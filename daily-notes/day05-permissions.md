# Day 5：权限管理

## 学习目标
- 理解 `ls -l` 输出
- 用数字和符号修改权限
- 更改文件所有者

## 常用命令
| 命令 | 作用 |
|------|------|
| `chmod +x file` | 添加执行权限 |
| `chmod 755 file` | 设置 rwxr-xr-x |
| `chmod 644 file` | 设置 rw-r--r-- |
| `chown user file` | 更改所有者 |
| `ls -l` | 查看权限字符串 |

## 权限数字含义
- `r` = 4，`w` = 2，`x` = 1
- `755` = rwxr-xr-x（用户全权，组和其他可读可执行）
- `644` = rw-r--r--（用户可读写，组和其他只读）

## 踩坑记录
`脚本必须要有执行权限（x）才能运行`
`chown需要sudo权限`
