# Day 10：脚本编写入门

## 学习目标
- 创建和执行 Shell 脚本
- 使用变量和命令替换
- 编写自动化备份脚本

## 常用命令
| 命令 | 作用 |
|------|------|
| `#!/bin/bash` | 脚本解释器声明 |
| `chmod +x script.sh` | 添加执行权限 |
| `./script.sh` | 执行脚本 |
| `$(command)` | 命令替换，执行并返回结果 |


##记录
`脚本必须有执行权限（chmod +x）才能运行`
`变量赋值不能有空格`
`命令替换$(...)比反引号好`
`#!/bin/bash必须是脚本第一行`
