# Day 7：进程管理

## 学习目标
- 后台运行程序
- 查看进程列表
- 终止进程
- 实时监控系统

## 常用命令
| 命令 | 作用 |
|------|------|
| `command &` | 后台运行 |
| `ps aux` | 查看所有进程 |
| `ps aux | grep name` | 过滤特定进程 |
| `kill PID` | 终止进程 |
| `kill -9 PID` | 强制终止 |
| `top` | 实时系统监控（q 退出） |


##踩坑记录
`后台进程不会因终端关闭而终止（但WSL关闭会）`
`kill -9是最后手段，尽量用kill`
