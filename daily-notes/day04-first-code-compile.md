# Day 4：编写并编译 C 程序

## 学习目标
- 用 nano 编写 C 代码
- 用 gcc 编译
- 运行可执行程序
- 体验 vim 基本操作

## 常用命令
| 命令 | 作用 |
|------|------|
| `nano file.c` | 编辑源代码 |
| `gcc file.c -o output` | 编译生成可执行文件 |
| `./output` | 运行程序 |
| `vim file.c` | 使用 vim 编辑 |

## 实战练习
bash
cd ~/practice/day1
nano hello.c
